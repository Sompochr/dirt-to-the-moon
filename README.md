# Dirt to the Moon 🏍️🌕

เกมขี่มอเตอร์ไซค์วิบากข้ามเนิน (แนว Hill Climb) ภาพ Pixel Art สำหรับเล่นบนมือถือผ่าน Browser
ไม่ต้องติดตั้งแอป เปิดลิงก์แล้วเล่นได้เลย (แนะนำให้ถือมือถือแนวนอน)

> **สถานะ: Phase 1** มีด่าน 1 (Green Meadow) ที่เล่นได้ครบทุกกติกา
> Phase 2 จะเพิ่มด่าน 2-5 (เหมืองแร่ → ดวงจันทร์), ระบบอัปเกรด, เสียงและเพลง

## วิธีเล่น

| การควบคุม | มือถือ | คอมพิวเตอร์ |
|---|---|---|
| คันเร่ง (GAS) | แตะค้างที่ **ครึ่งขวา** ของจอ | ปุ่ม → หรือ D |
| เบรก / ถอยหลัง (BRAKE) | แตะค้างที่ **ครึ่งซ้าย** ของจอ | ปุ่ม ← หรือ A |
| เอนตัวกลางอากาศ | GAS = เอนหลัง, BRAKE = เอนหน้า | เหมือนกัน |
| พลิกรถเมื่อคว่ำ | ปุ่ม **FLIP** (เสียเวลา 3 วินาที) | Space หรือ F |
| หยุดเกม | ปุ่ม ⏸ มุมขวาบน | Esc หรือ P |

**กติกา**
- ไปให้ถึงเส้นชัยก่อนหมดเวลา
- น้ำมันลดลงตลอดเวลา (ลดเร็วขึ้นเมื่อเร่ง) เก็บ **ถังน้ำมันสีแดง** เพื่อเติมให้เต็ม
- น้ำมันหมดหรือหมดเวลา = แพ้ (แต่ยังได้เหรียญที่เก็บมาแล้ว)
- ดาว: ถึงเส้นชัย = ⭐, เร็วกว่าเกณฑ์ = ⭐⭐, เร็วมาก = ⭐⭐⭐
- ตีลังกา (Backflip / Frontflip) แล้วลงพื้นได้ = ได้เหรียญโบนัส +25

## ปรับแต่งเกมเอง (ไม่ต้องเขียนโปรแกรมเป็น)

แก้ตัวเลขใน 2 ไฟล์นี้ได้เลย ทุกบรรทัดมีคำอธิบายภาษาไทย

- **`src/config.js`**: ความรู้สึกในการขับ เช่น แรงเครื่องยนต์ ความเร็ว แรงเบรก การเอนตัว อัตรากินน้ำมัน ค่าปรับเวลาเมื่อกด FLIP
- **`src/levels.js`**: ข้อมูลด่าน เช่น ความยาว เวลา เกณฑ์ดาว ความสูงของเนิน ตำแหน่งทางลาด ระยะห่างถังน้ำมัน
  - เปลี่ยนเลข `seed` เพื่อสุ่มรูปเนินใหม่ทั้งหมด

## โครงสร้างไฟล์

```
index.html            หน้าเว็บหลัก
style.css             จัดหน้าจอให้เต็มจอมือถือ และให้ภาพ pixel คมชัด
vendor/planck.min.js  ระบบฟิสิกส์ planck.js (Box2D) — MIT License
src/
  main.js     จุดเริ่มเกม: game loop, กล้อง, สลับหน้าจอ
  config.js   ⚙️ ค่าปรับแต่งเกม
  levels.js   🗺️ ข้อมูลด่าน
  terrain.js  สร้างเนิน ทางลาด เหรียญ ถังน้ำมัน จากข้อมูลด่าน
  bike.js     ฟิสิกส์มอเตอร์ไซค์ (ล้อ โช้ค เครื่องยนต์ เบรก เอนตัว)
  game.js     กติกาของ 1 รอบการเล่น: เวลา น้ำมัน FLIP เก็บของ ตีลังกา
  render.js   วาดฉาก: ท้องฟ้า ภูเขา พื้นดิน รถ
  sprites.js  ภาพ pixel art ทั้งหมด (วาดด้วยโค้ด ไม่มีไฟล์รูป)
  font.js     ฟอนต์ pixel 5x7
  ui.js       HUD เมนู ปุ่ม หน้าสรุปผล
  input.js    รับการแตะหลายนิ้ว เมาส์ และคีย์บอร์ด
  save.js     บันทึกความคืบหน้าในเครื่อง (localStorage)
```

## รันบนคอมพิวเตอร์ตัวเอง

เกมเป็นไฟล์เว็บธรรมดา ไม่ต้อง build แต่ต้องเปิดผ่าน web server (เปิดไฟล์ตรง ๆ ไม่ได้เพราะใช้ JavaScript modules)

```bash
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

เพิ่ม `?debug` ท้าย URL เพื่อเปิดเครื่องมือทดสอบ (`window.__dttm` ใน Console)
