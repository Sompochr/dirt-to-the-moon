# Dirt to the Moon 🏍️🌕

เกมขี่มอเตอร์ไซค์วิบากข้ามเนิน (แนว Hill Climb) ภาพ Pixel Art สำหรับเล่นบนมือถือผ่าน Browser
ขี่จากทุ่งหญ้า ผ่านเหมืองแร่และอุโมงค์ใต้ดิน ไปจนถึงดวงจันทร์

**เล่นได้ที่:** https://dirt-to-the-moon.vercel.app (ถือมือถือแนวนอน)

## ติดตั้งเป็นแอปบนมือถือ

- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ □↑ → "เพิ่มไปยังหน้าจอโฮม"

เมื่อติดตั้งแล้วจะเปิดเต็มจอเหมือนแอป และเล่นได้แม้ไม่มีอินเทอร์เน็ต (หลังจากเคยเปิดครั้งแรกแล้ว)

## วิธีเล่น

| การควบคุม | มือถือ | คอมพิวเตอร์ |
|---|---|---|
| คันเร่ง (GAS) | แตะค้างที่ **ครึ่งขวา** ของจอ | ปุ่ม → หรือ D |
| เบรก / ถอยหลัง (BRAKE) | แตะค้างที่ **ครึ่งซ้าย** ของจอ | ปุ่ม ← หรือ A |
| เอนตัวกลางอากาศ | GAS = เอนหลัง, BRAKE = เอนหน้า | เหมือนกัน |
| พลิกรถเมื่อคว่ำ | ปุ่ม **FLIP** (เสียเวลา 3 วินาที) | Space หรือ F |
| หยุดเกม | ปุ่ม ⏸ มุมขวาบน | Esc หรือ P |

**กติกา**
- ไปให้ถึงเส้นชัยก่อนหมดเวลา
- น้ำมันลดลงตลอดเวลา (ลดเร็วขึ้นเมื่อเร่ง) เก็บ **ถังน้ำมันสีแดง** เพื่อเติมให้เต็ม
- น้ำมันหมดหรือหมดเวลา = แพ้ (แต่ยังได้เหรียญที่เก็บมาแล้ว)
- ดาว: ถึงเส้นชัย = ⭐, เร็วกว่าเกณฑ์ = ⭐⭐, เร็วมาก = ⭐⭐⭐ (ดาว 3 ดวงในด่านหลัง ๆ ต้องอัปเกรดรถด้วย)
- ตีลังกา (Backflip / Frontflip) แล้วลงพื้นได้ = เหรียญโบนัส +25
- ผ่านด่านไหน ด่านถัดไปจะปลดล็อก

**ด่านทั้ง 5**

| ด่าน | ชื่อ | ฉาก | จุดเด่น |
|---|---|---|---|
| 1 | Green Meadow | ทุ่งหญ้า | เนินนุ่ม ๆ ทางลาด 3 จุด |
| 2 | Windy Hills | ทุ่งหญ้า | เนินชันขึ้น สะพานไม้ที่ยวบได้ 2 แห่ง |
| 3 | Open Pit | เหมืองเปิดยามเย็น | เนินขั้นบันได รางรถเหมือง แผ่น Boost |
| 4 | Deep Shaft | อุโมงค์ใต้ดิน (โทนกลางคืน) | ตะเกียงตามทาง สะพานรางรถเหมือง |
| 5 | Moon Base | ดวงจันทร์ | แรงโน้มถ่วงต่ำ ลอยนาน หลุมอุกกาบาตตื้น ๆ |

**Garage (อัปเกรด):** ใช้เหรียญซื้ออัปเกรด 3 อย่าง อย่างละ 5 ระดับ
เข้าได้จากหน้าแรก หน้าเลือกด่าน หรือปุ่ม **UPGRADE** ตอนจบด่าน (มีเครื่องหมาย ! เมื่อเหรียญพอซื้อ)
- **ENGINE:** แรงขึ้นและเร็วขึ้น
- **FUEL TANK:** ถังน้ำมันใหญ่ขึ้น
- **TIRES:** ยางเกาะถนนดีขึ้น ไต่เนินชันได้ดีขึ้น

**เสียง:** ปุ่มลำโพง (เสียงเอฟเฟกต์) และปุ่มโน้ตดนตรี (เพลง) อยู่ที่หน้าแรกและหน้าหยุดเกม
บน iPhone ถ้าเปิดสวิตช์ปิดเสียง (Silent) ไว้ จะไม่ได้ยินเสียงเกม

## ปรับแต่งเกมเอง (ไม่ต้องเขียนโปรแกรมเป็น)

แก้ตัวเลขใน 2 ไฟล์นี้ได้เลย ทุกบรรทัดมีคำอธิบายภาษาไทย

- **`src/config.js`**: ความรู้สึกในการขับ (แรงเครื่อง ความเร็ว เบรก การเอนตัว), อัตรากินน้ำมัน, ค่าปรับ FLIP, แผ่น Boost, ราคาและผลของอัปเกรด, ความดังเสียง
- **`src/levels.js`**: ข้อมูลแต่ละด่าน เช่น ความยาว เวลา เกณฑ์ดาว แรงโน้มถ่วง ความสูง/ความชันของเนิน ตำแหน่งทางลาด สะพาน แผ่น Boost และระยะห่างถังน้ำมัน
  - เปลี่ยนเลข `seed` เพื่อสุ่มรูปเนินใหม่ทั้งหมด
  - ถ้าตั้ง `maxSlope` สูงเกิน 0.66 รถที่ยังไม่อัปเกรดอาจไต่เนินไม่ขึ้น

```

sw.js                 ให้เล่นออฟไลน์ได้
icons/                ไอคอนแอป (สร้างด้วย tools/make-icons.js)

src/
  main.js     จุดเริ่มเกม: game loop, กล้อง, สลับหน้าจอ, เสียงตามหน้าจอ
  config.js   ⚙️ ค่าปรับแต่งเกม
  levels.js   🗺️ ข้อมูลด่าน
  themes.js   สี ฉากหลัง ของประดับ และเพลงของแต่ละฉาก
  terrain.js  สร้างเนิน ทางลาด สะพาน แผ่น Boost เหรียญ ถังน้ำมัน
  bike.js     ฟิสิกส์มอเตอร์ไซค์ + ผลของอัปเกรด
  game.js     กติกาของ 1 รอบการเล่น: เวลา น้ำมัน FLIP เก็บของ ตีลังกา Boost
  render.js   วาดฉาก: ท้องฟ้า ภูเขา พื้นดิน สะพาน ตะเกียง รถ
  sprites.js  ภาพ pixel art ทั้งหมด (วาดด้วยโค้ด ไม่มีไฟล์รูป)
  font.js     ฟอนต์ pixel 5x7
  ui.js       HUD เมนู หน้าเลือกด่าน Garage หน้าสรุปผล
  input.js    รับการแตะหลายนิ้ว เมาส์ และคีย์บอร์ด
  audio.js    เสียงเครื่องยนต์ เสียงเอฟเฟกต์ และเพลง 8-bit (สร้างด้วยโค้ด)
  save.js     บันทึกความคืบหน้าในเครื่อง (localStorage)
  util.js     ฟังก์ชันคณิตศาสตร์เล็ก ๆ ที่ใช้ร่วมกัน
tools/
  make-icons.js  สร้างไฟล์ไอคอนใหม่จากภาพในเกม
```

## รันบนคอมพิวเตอร์ตัวเอง

เกมเป็นไฟล์เว็บธรรมดา ไม่ต้อง build แต่ต้องเปิดผ่าน web server (เปิดไฟล์ตรง ๆ ไม่ได้เพราะใช้ JavaScript modules)

```bash
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

เพิ่ม `?debug` ท้าย URL เพื่อเปิดเครื่องมือทดสอบ (`window.__dttm` ใน Console)

## การเผยแพร่

repo นี้เชื่อมกับ Vercel แล้ว เมื่อ push ขึ้น branch `main` ระบบจะ deploy ให้อัตโนมัติ
ความคืบหน้าของผู้เล่น (เหรียญ ดาว อัปเกรด) เก็บในเครื่องของผู้เล่นเอง ถ้าล้างข้อมูล Browser ความคืบหน้าจะหายไป
